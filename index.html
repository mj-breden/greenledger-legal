GreenLedger

GreenLedger is a personal, self-hosted plant inventory and journal that runs on a private home network. It is used by one household to catalogue houseplants and a vegetable garden.

It is not a public service and has no public users. It uses the Google Drive API only to store the owner's own nightly backups in the owner's own Drive.
